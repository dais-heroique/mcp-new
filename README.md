# mcp-new

This repository contains the **MCP Release Readiness** product: a local, read-only static analyzer and commercial delivery kit for MCP servers.

## Contents

- [`mcp-readiness/`](mcp-readiness/) — installable Python CLI, tests, examples and generated report format.
- [`RESEARCH_NOTES.md`](RESEARCH_NOTES.md) — research on the MCP 2026-07-28 baseline, transports, authorization and EMA.
- [`business/`](business/) — offer, landing page, outreach, demo script and legal review notes.
- [`NEXT_STEPS.md`](NEXT_STEPS.md) — readiness status and 14-day validation plan.

The analyzer is local-only and non-destructive. A non-demo scan requires explicit owner authorization. It never claims certification or legal compliance.
