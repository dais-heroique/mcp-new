# Launch kit — testeurs et acheteurs

## Message de découverte

Bonjour, j’ai vu que vous construisez ou maintenez un projet MCP public. Je travaille sur MCP Production Readiness, un check local et read-only qui produit un score, des écarts, un badge et des corrections guidées avant publication. Je cherche quelques équipes volontaires pour tester le parcours sur une copie de dépôt, sans accès distant ni modification de code. Seriez-vous intéressé par un test court ?

## Proposition d’audit

Merci pour votre retour. Le pilote complet est un **MCP Readiness Audit** borné : dépôt ou copie fourni avec autorisation, score et gate, rapport Markdown/JSON, badge, guided fixes, preview de diff et restitution. L’hypothèse de prix de lancement est 149–499 € selon le périmètre. Il ne s’agit ni d’un pentest ni d’une certification. Si le pilote est utile, nous pouvons ensuite discuter d’un check automatique sur chaque PR.

## Relance non agressive

Bonjour, je me permets une seule relance concernant le test MCP Readiness. Même un retour négatif sur les critères qui comptent dans une release nous aiderait. Si le sujet n’est pas prioritaire, aucun problème; je ne relancerai pas davantage.
